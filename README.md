# seba2390/tap

Homebrew tap for [Pistachio](https://github.com/seba2390/pistachio), a fast, native desktop app
for the [pi coding agent](https://pi.dev) written in Rust.

```bash
brew install --cask seba2390/tap/pistachio
```

Update with `brew upgrade --cask pistachio`. Pistachio needs [pi](https://pi.dev)
(`npm i -g @earendil-works/pi-coding-agent`).

The cask is updated automatically by Pistachio's release workflow.
